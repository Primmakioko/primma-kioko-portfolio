# Primma Kioko Portfolio

This is a plain HTML, CSS, and JavaScript portfolio website designed for GitHub Pages.

## Project files

- `index.html`: page content and portfolio text
- `styles.css`: visual styles and responsive layout
- `script.js`: optional interactive behavior
- `assets/images/profile/`: profile photo
- `assets/images/projects/`: project cover and gallery images
- `assets/certificates/`: certificate files
- `assets/documents/`: CV PDF

## Adding a project

Add a folder inside `assets/images/projects/`, then follow that folder's `README.txt`. Add the project's text and image paths to `index.html` when the portfolio content is built.

## Publishing with GitHub Pages

The site can be published directly from the repository root because `index.html` is at the top level. Configure GitHub Pages to deploy from the repository's main branch and root folder.
